# Портфолио команды

Сайт-портфолио команды разработчиков (сайты, бэкенд, приложения, боты, скрипты, парсеры) со встроенной админкой.

- 🎨 Тёмный дизайн, анимации: прелоадер, печатающийся код, меняющиеся слова, магнитные кнопки с бликом, 3D-наклон карточек, появление при скролле, счётчики, бегущая строка, таймлайн
- 🗂️ Работы с фильтром по категориям, сортировкой (новые / старые / А–Я / избранные) и поиском
- 🎞️ Окно работы с галереей: фото, видео, YouTube
- 🔐 Кнопка «Вход» справа сверху → админка `/admin`
- ✏️ В админке меняются **все тексты сайта**, работы, обложки, галереи, загружаются файлы (есть медиатека) и меняется пароль
- ⚡ Без зависимостей: только Node.js 18+, никаких `npm install`

## Запуск

```bash
cp .env.example .env    # укажите ADMIN_EMAIL и ADMIN_PASSWORD
npm start               # http://localhost:3000, админка: http://localhost:3000/admin
```

## Хостинг

Нужен хостинг с Node.js и **постоянным диском** (тексты и загруженные файлы хранятся в `data/` и `uploads/`):

- **VPS** (любой): `git clone`, создать `.env`, запустить через `pm2 start server.js` или systemd, сверху Nginx + HTTPS
- **Docker**: `docker build -t portfolio . && docker run -d -p 3000:3000 -v portfolio:/app/storage --env-file .env portfolio`
- **Render / Railway / Amvera**: подключить репозиторий, команда запуска `npm start`, задать переменные окружения, подключить диск и указать `DATA_DIR` / `UPLOAD_DIR` на него

> GitHub Pages не подойдёт — там нельзя запустить сервер для админки.

## Структура

```
server.js                 сервер + API
data/default-content.json тексты и примеры работ по умолчанию
public/index.html         сайт
public/admin.html         админка
public/css, public/js     стили и скрипты
uploads/                  загруженные файлы (не в git)
```

## Безопасность

- Пароль хранится только в `.env` / в виде хэша (scrypt) в `data/auth.json` — не в репозитории
- Сессия в HttpOnly-cookie, защита от CSRF, ограничение попыток входа (8 за 15 минут)
- После первого входа можно сменить почту и пароль во вкладке «Аккаунт»
